## Important

- This repository was created in a ChatGPT isolated workspace; it is **not yet** on the user's Mac and **not yet** pushed to GitHub.
- History commits are sequential *archival snapshots*, not proof each version was derived linearly from its predecessor.
- See `docs/regression_matrix.md` for in-game observations.
- `src/` is the currently checked-out historical version; inspect tags to compare versions.
- Original game/mod assets belong to their respective creators. Review any license/redistribution terms before making this repository public.
